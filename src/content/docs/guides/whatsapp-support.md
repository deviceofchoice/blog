## Which Operating Systems Are Compatible?

WhatsApp is one of the most widely used messaging platforms in the world. Over time older devices and OS versions lose compatibility. Below is a summary of the current support status across mobile and desktop OSes.


## Mobile Support (Android, iOS, KaiOS)
- ### **Android**

WhatsApp currently supports Android 5.0 (Lollipop) and newer. Any device running Android 5.0 or above should be able to install and use WhatsApp, provided it supports SMS or calls for verification. This gives Android a much wider range of supported devices compared to iOS, meaning many older Android phones can still be used with the app.

WhatsApp has announced that starting January 1, 2025 it will drop support for devices running Android 4.4 (KitKat) or earlier. 

- ### **iOS (iPhone)**

Currently WhatsApp works on iPhones running iOS 15.1 or newer. Devices with earlier iOS versions are being phased out of compatibility.

As of the date of this article, the oldest iPhone models still supported by WhatsApp are the **iPhone SE** and **iPhone 6s**, both supporting iOS up to version 15.8.

- ### **KaiOS**

WhatsApp is no longer supported on KaiOS devices, including models like the JioPhone, Nokia 8110 4G, Nokia 2720 Flip, and Nokia 8000 4G.

Support officially ended for users who had not previously logged in on June 25, 2024, and completely ceased for all devices on January 10, 2025. The app is also no longer available in the KaiStore, so it cannot be downloaded or installed on KaiOS devices.
